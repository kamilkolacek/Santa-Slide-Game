# Santa's Slide

A single-file HTML5 touch game for toddlers. Tap the Snowman, Reindeer or Elf and they slide a present down their lane; Santa hops over and catches it in his sack. No failing, no text.

- Open `index.html` in a tablet browser (landscape) and tap to start.
- Parent exit: press and hold the top-left corner for 1.5 seconds.
- All art is vector shapes drawn in code and all sound is synthesized with Web Audio. Music is public-domain carols (Jingle Bells, We Wish You a Merry Christmas, Silent Night).
- Swap in real art via `window.SANTA_ART` (see the comment at the top of the script).
